Quick Guide

1
Initial setup

On repuls.io, open Settings → Controls and select Reset To Default. This is a one-time step. After that, manage all keybinds from this extension rather than the game's own menu.

2
Rebinding a key

Select the key box beside an action, then press the key you want to assign. Changes save automatically. Press Esc to cancel.

3
Extension On/Off (Ctrl + K)

Use this master switch to pause all keybinds, for example when typing in chat. While off, every key behaves as normal. Disabling it also releases any open scope, sprint, or fire input so nothing remains stuck. Press the shortcut again to re-enable.

4
Hold and Toggle modes

Hold activates the action while the key is pressed. Toggle switches it on with one press and off with the next. Scope and Sprint support both modes, and Fire behaves like holding left-click. Each mode can be enabled or disabled independently.

5
Key conflict warning

A warning appears when a single key is assigned to more than one action. Reassign one of them to clear it.

6
Troubleshooting

Confirm that Extension On/Off is enabled and that the in-game keybinds are set to default. After installing or updating the extension, reload the game tab. Reset To Default restores all bindings.
